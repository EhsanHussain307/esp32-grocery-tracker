# 🥫 ESP32 Grocery Tracker

An IoT-based grocery tracking system using:

- ESP32
- 4x4 Keypad
- OLED Display
- MQTT Communication

## Features

- Add grocery items using keypad
- Categorized storage (Fridge / Pantry)
- MQTT publish to broker
- Real-time updates

## Hardware

- ESP32 DevKit
- 4x4 membrane keypad
- SSD1306 OLED
- WiFi connection

## MQTT Topic

home/grocery/item/set
